# 🚀 ¡Nuevo lanzamiento de WinTTS! — v1.0.1

WinTTS 1.0.1 convierte el lector local en un editor de narración mucho más práctico, manteniendo todo el procesamiento y el audio dentro de Windows.

### 🌟 Novedades destacadas

- ⏯️ **Control completo**: reproducir, pausar, reanudar y detener.
- 🎚️ **Narración ajustable**: voz intercambiable durante la lectura, volumen, velocidad y tono.
- ✂️ **Lectura selectiva**: leer una selección y marcar fragmentos para omitirlos.
- 📝 **Markdown práctico**: vista renderizada y modo fuente con sintaxis no narrada resaltada en ámbar.
- 💾 **Audio local**: exportación WAV cancelable con la misma configuración de lectura.
- 🎨 **Interfaz refinada**: tema oscuro consistente, controles accesibles y mejor contraste.

WinTTS continúa siendo gratuito, privado, offline y publicado bajo licencia MIT. 💜
