# 🚀 ¡Nuevo Lanzamiento de WinTTS! — v1.0.0 ("Alfajor")

¡Nos complace anunciar la primera versión pública de **WinTTS**! 🎉

### 📝 Resumen
Esta versión establece la base de la aplicación de escritorio nativa para Windows (WPF/C#) construida bajo .NET 10. Su lógica principal permite realizar síntesis de voz (TTS) 100% local, offline y privada.

### 🌟 Novedades Destacadas
- 🎙️ **Síntesis Local**: Lectura mediante voces nativas del sistema operativo sin transmitir datos a internet.
- 🧹 **Limpieza de Markdown**: Motor de preprocesamiento automático que remueve negritas, títulos, enlaces y código antes de la lectura para evitar ruidos de sintaxis.
- 🎨 **Diseño Moderno**: Interfaz oscura con acentos turquesa ("Ely VTuber" style) y barra de título personalizada.
- 🔄 **Hot-Swap de Voces**: Permite seleccionar dinámicamente voces del sistema en tiempo real y realizar ajuste fino de volumen.
- 🤖 **Reglas del Agente**: Archivo `agent.md` configurado para modelos de IA recomendados (2026) y flujos de desarrollo óptimos.
